# DecodeLabs-Internship-Project1

MedCore-Hospital-static-webpage

A pixel-perfect, fully responsive medical website homepage designed and built to meet strict internal engineering blueprint requirements.

Task Objectives Achieved

12-Column Grid Architecture: Implemented a highly precise, custom multi-column grid layout. Divided the container layout into balanced symmetrical halves spanning 3 columns per content track.

Quadrant Content Grid: Successfully designed an advanced grid module mapping full-height standard display cards side-by-side with vertical and horizontal halved-height quadrant blocks.

Semantic HTML5: Built using clean semantic elements (header, nav, main, article, footer) ensuring clean document structure and zero div soup.

Blueprint Constraints: Exactly satisfied rigid spacing rules including an 80px fixed header, 400px minimum fixed footer architecture, 24px grid gutters, and a strict 60px margin module separation gap.

Pure CSS Responsive Toggle: Designed a fully responsive hamburger navigation menu using the native CSS Checkbox Hack, ensuring flawless responsive behavior on mobile and tablet screen viewports with zero JavaScript dependencies.

Local Asset Optimization: Managed media assets directly inside the local directory structure using highly efficient .avif graphic files for fast loading and crisp visuals.

Technologies Used

Semantic HTML5 Vanilla CSS3 using CSS Grid matrix and Flexbox layout alignments Local AVIF Media Assets

Layout Strategy Breakdown

Desktop Layout (above 968px): Locks directly onto a rigid 1200px content matrix, maintaining strict column constraints.

Mobile and Tablet Layout (below 968px): Collapses dynamically into fluid vertical columns, scaling font sizes and converting multi-row footers into balanced stacks to eliminate horizontal scroll clipping.
